# v0.0.11

BloodBuddy 0.0.11 lets you choose how dates, numbers and patient names are shown and typed.

## What is new

- **A Settings screen.** Tap the gear next to the information icon on the start screen. You can choose the date format (System default, `yyyy-MM-dd`, `dd.MM.yyyy`, `dd/MM/yyyy` or `MM/dd/yyyy`), the decimal separator (System default, point or comma) and how patient names are shown (`Anna Müller` or `Müller, Anna`). Every option shows an example, and System default shows what your device resolves to.
- **Changes apply at once.** Reading lists and details, trend charts, the import review, patient lists and the About screen all follow your choice immediately, and System default follows the device language if you change it.
- **Typing follows the same format.** Date and number fields show the pattern you chose. Text in another format is flagged with a message that names the expected pattern or separator, and it is never guessed: for example `1.234` is not accepted when the decimal comma is selected, because it could mean 1.234 or 1234.
- **Names in your order.** Patient lists are sorted by the name as shown. A person stored as `Müller, Anna` is offered when you add or import `Anna Müller` with the same birth date. You still confirm every match, and profiles are never merged.

## Changed behavior

- With System default, dates now appear as numbers in your device's style instead of month names (for example `13.11.2026` or `11/13/2026` instead of `Nov 13, 2026`), and chart month labels are numeric too. Numbers use your device's decimal mark. You can pick a different format in Settings at any time.
- Names are shown given name first by default, so a patient stored as `Müller, Anna` now appears as `Anna Müller`. Only names with exactly one comma or exactly two words are reordered; any other name is shown exactly as stored.
- Number input is stricter. A value typed with the other decimal mark is flagged instead of silently converted, including in the import review, which used to turn a comma into a point.
- If you switch a setting while a field holds text in the wrong format, the text stays as typed and stays flagged until you edit it.

## Privacy

- Your choices are saved only on your device, in a small preferences file separate from the patient data. Nothing is uploaded and no new permissions are requested.
- Stored data does not change: birth dates, reading dates, values, limits and names are saved exactly as before, whatever you choose, so switching settings never alters or duplicates a patient or reading.

## Known limitations

- Dates written with slashes in a report (for example `05/01/2024`) are still not guessed, whatever setting you choose. You enter those dates yourself.
- Names with more than two words (for example `Anna Maria von Berg`) are not reordered.
- Month names such as `Nov` are not offered as a date style.

## Compatibility

Requires Android 7.0 or newer. Existing patients, readings, charts and the import results are unchanged. This release is signed with the same key as earlier releases.
