# v0.0.14

BloodBuddy 0.0.14 makes the trend chart easier to use with a long history.

## What is new

- **Tests in alphabetical order.** The test and unit picker in the trend view is sorted alphabetically by test name. The same test in different units stays together, ordered by unit.
- **The chart opens at the newest reading.** The newest date of the selected test is visible when you open the chart, and again after you change the test or the grouping. Scrolling back to older dates works as before.
- **Date buttons.** Four buttons below the chart, `<<`, `<`, `>` and `>>`, move the chart to the first date, the next older date, the next newer date and the last date of the selected test. A button that has nowhere to go is greyed out. The buttons follow the chosen grouping, so with Month they step from month to month.
- **Reference limits as lines.** The lower and upper limit are drawn as dashed grey lines. A line holds a limit until a later reading changes it, and it is not broken by readings that have no limit. A limit that is known for one reading only is drawn across the whole chart. The legend names only the limits the selected test has.

## Changed behavior

- The first test shown is now the first one alphabetically, no longer the one with the latest reading.
- Limits no longer have their own colours or point markers. The date label you get when you touch the chart still shows the lower and upper limit of that date.

## Privacy

- Everything works offline. Nothing is uploaded and no new permissions are requested.

## Compatibility

Requires Android 7.0 or newer. The database format is unchanged, so existing patients and readings are kept. This release is signed with the same key as earlier releases.
