# v0.0.12

BloodBuddy 0.0.12 makes report imports more robust and checks them against what is already saved for the patient.

## What is new

- **Better recognition of real lab reports.** The importer now tells the report's blocks apart: the provider, the patient line (also forms like `Patient: [id] Name, geb.: date` or `Fall: id; Name, geb.: date`), print dates and display periods, the result table and the footer. Only table rows become readings, and print dates are never used as measurement dates. Tables with a `Parameter | Normwert | date` header, stacked date headers with times and order numbers, section headings, flagged values such as `*12.7*` or `[+] 507`, and scans whose headers are centred over left-aligned columns are read.
- **Reference limits and units from the table.** A reference cell like `150 - 400 G/l` or `< 0.5 mg/dl` gives the limits and the unit. A unit in the test label such as `Thrombozyten [G/l]` is read, and a unit the scanner garbled (for example `G/I`) is read as the one known unit it looks like. If nothing matches, the unit stays unknown and the row is flagged.
- **Units can stay unknown.** If a report prints no unit, you can mark the unit unknown for a row and still save it. Such readings are shown as "unit unknown" and kept as their own series.
- **Comparison with saved readings.** For an existing patient the review shows notes per row: already saved for this date, a different unit than before, a value far outside the patient's earlier values, and different limits. A unit can be suggested from the patient's history; you decide. Nothing is changed or blocked by these notes.
- **Completing earlier units.** When a later report supplies a unit for tests saved earlier with unit unknown, the app offers to complete them, one test at a time. If the earlier values only fit a related unit (for example mg/l against mg/dl), the offer shows the units, the conversion factor and each converted value, and applies the conversion only after you confirm.
- **Matching test names across labs.** `C-reak.Protein` and `C-reaktives Protein (CRP)` are recognized as the same test, using the name itself and a small bundled catalog of common blood tests. The trend view shows one chart per test and unit.

## Changed behavior

- Saved readings can now change in one case: confirming a unit completion sets the unit and, when you accept a conversion, converts the value and its reference limits. Names, dates and patients never change.
- Specimen terms and lab codes in a test name, such as `(EDTA-Blut) (ERY)`, are no longer stored with the name.

## Privacy

- Everything works offline. The test catalog is bundled with the app, nothing is uploaded and no new permissions are requested.
- The About screen shows the LOINC and UCUM notices that come with the catalog.

## Known limitations

- Scanner damage can still change a name or hide a unit; unknown units stay unknown, and you correct them in the review.
- Values are not converted for display. The same test in two different units shows as two charts.
- Readings cannot be deleted in the app yet.

## Compatibility

Requires Android 7.0 or newer. The database format is unchanged, so existing patients and readings are kept. This release is signed with the same key as earlier releases.
